# Eldritch Surge Wiki

**Eldritch Surge 1.6.0 · Minecraft 26.3 · Fabric**

Eldritch Surge expands Minecraft’s enchantment system with 106 custom enchantments, an Advanced Enchanting Table, spell books, enchantment categories, anvil combinations and configurable world rules.

## Quick facts

- **Minecraft:** 26.3
- **Mod release:** 1.6.0
- **Loader:** Fabric
- **Required libraries:** Fabric API and Fabric Language Kotlin
- **EnchLib:** optional integration; Eldritch Surge and EnchLib remain separate mods.
- **World rules:** saved with the world and synchronized from the logical server to connected clients. Only operators with permission level 2 or higher can submit rule changes.

> Compatibility and mechanics are documented from the current source definitions. The workbook marks behaviors that still need in-game confirmation.
